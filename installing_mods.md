# Installing 3rd Party Mods for Cataclysm: Dark Days Ahead

### 1. Downloading the mod

Many third-party Cataclysm mods are hosted on github. 

These can be downloaded either by clicking `Code -> Download Zip`

<kbd><img src="./resources/download-zip.png" width="500" style="border: solid 1px black;" /></kbd>

or by finding a file on the mod's `Releases` page

<kbd><img src="./resources/release-download.png" width="500" style="border: solid 1px black;" /></kbd>

### 2. Go to the game directory and find the mods folder

<kbd><img src="./resources/game-folder.png" width="500" style="border: solid 1px black;" /></kbd>

### 3. Unpack the mod into its own folder

<kbd><img src="./resources/unpack.png" width="500" style="border: solid 1px black;" /></kbd>

### 4. Check the mod is available when creating a new world

<kbd><img src="./resources/select-mod.png" width="500" style="border: solid 1px black;" /></kbd>

> <sup>**Note:**</sup>    
> <sup>If you play Cataclysm with a launcher, the process of installing mods might be different for you.</sup>    
> <sup>Check with the launcher's project for information on manually installing mods.</sup>
